# Python Taxi Data Analysis & Visualization
A Python data analysis project using the Seaborn Taxis dataset to explore taxi trip data, handle missing values, and visualize patterns in fares, trip distances, payment methods, and pickup boroughs.
# Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
# Key Activities
- Explored the dataset structure, columns, data types, and missing values.
- Inspected categorical values and their frequencies.
- Handled missing values using median imputation for numerical columns and mode imputation for categorical columns.
- Created visualizations to analyze fare trends, trip distributions, payment methods, and relationships between numerical variables.
# Visualizations
- Line chart
- Bar chart
- Pie chart
- Histogram
- Box plot
- Count plot
- Scatter plot
- Correlation heatmap
- Pair plot
- Violin plot
# Objective
To practise Python-based data cleaning, exploratory data analysis (EDA), and data visualization to identify patterns and understand taxi trip data.
